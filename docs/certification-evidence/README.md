# Project verification evidence

These artifacts record project-run compatibility checks. They are not Microsoft
certification, sponsorship, endorsement, or approval.

The JSON and Markdown files contain functional verdicts, engine versions,
assertions, cleanup outcomes, and zero-residue results. JUnit output is also
generated for local/CI use but remains untracked under the repository hygiene
policy. Engine timing data and run timestamps are deliberately excluded so the
artifacts cannot be used as benchmark disclosures.
