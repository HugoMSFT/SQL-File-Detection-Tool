# Open the tool

Select the **SQL File Detection Tool** icon in the Activity Bar.

The full interface opens in an editor tab straight away from bundled HTML, CSS
and JavaScript. There is no interpreter check, no virtual environment, no
package install, no port and no browser tab. Everything runs in the VS Code
extension host.

Prefer the Activity Bar surface? Set **SQL File Detection Tool: Default View**
to **sidebar**. Both surfaces share one state, so nothing is analyzed twice.
