# Open the tool

Select the **SQL File Detection Tool** icon in the Activity Bar.

The view renders straight away from bundled HTML, CSS and JavaScript. There is
no interpreter check, no virtual environment, no package install, no port and no
browser tab. Everything runs in the VS Code extension host.

Prefer a wider surface? Run **SQL File Detection Tool: Open in Editor** to move
the same session into an editor tab. Both surfaces share one state, so nothing
is analyzed twice.
